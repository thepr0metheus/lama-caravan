# Диаграммы правил

Каждая диаграмма — то, что правило держит, а не форма кода: кто решает, где факт назван
один раз, и что нельзя сказать второй раз.

Номера правил совпадают с гвардом: `scripts/check_media_reader.py` нумерует правила в том
порядке, в котором их проверяет, и каждая диаграмма называет свой номер. Диаграмма показывает,
что в таблице обязано быть, а не каждый случай: таблицу бегает программа, и она же — источник
слов.

| Диаграмма | Что держит | Что проверяет |
| --- | --- | --- |
| `media-reader.md` | все семь правил одним видом: кто решает и где факт назван один раз | `check_media_reader.py` |
| `media-reader-01-vocabulary.md` | правило 1: словарь и те, кто его читает | список READERS |
| `media-reader-02-may-not.md` | правило 2: что файл не может сказать | список MAY_NOT |
| `media-reader-03-caption-and-key.md` | правило 3: форма подписи, поля ключа, версия слов | проверка ONCE |
| `media-reader-04-where-a-wiring-is-built.md` | правило 4: проводка строится только в `Wired::of` | проверка built |
| `media-reader-05-one-answer-one-code.md` | правило 5: один ответ — один код, и `Itself` до обещания | список CODES |
| `media-reader-06-the-table.md` | правило 6: таблица и случаи, которых в ней не может не быть | проверка таблицы |
| `media-reader-07-the-reading.md` | правило 7: чтение борда, `known_name` и `pick` | проверка READING |

Читается так: факт вверху, тот, кто его читает, ниже. Стрелка — «читает из». Пунктир — «держит
к». Штриховая рамка — отсутствие, названное как отсутствие.
